# 🚀 MERN Stack - 90 Days Learning Journey

Welcome to my **90-Day MERN Stack Learning Journey**.

I am learning and practicing Full Stack Development using the MERN Stack through a structured, hands-on approach. This repository contains my daily practice, coding exercises, concepts, and projects.

---

## 🛠️ Tech Stack

- JavaScript
- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- Git & GitHub

---

## 🎯 Goals

- Build strong JavaScript fundamentals
- Learn React.js and component-based development
- Learn React Hooks and state management
- Build REST APIs using Node.js and Express.js
- Work with MongoDB and Mongoose
- Implement authentication using JWT and bcrypt
- Build complete full-stack MERN applications
- Learn deployment of web applications
- Build projects suitable for software development placements
